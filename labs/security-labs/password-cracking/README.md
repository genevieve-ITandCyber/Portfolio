# Password Cracking Lab

## Overview
This lab explores password cracking techniques using Kali Linux in a controlled virtual environment.

## Tools Used
- Kali Linux
- Hashcat
- John the Ripper (Johnny)
- CeWL

## Key Activities
- Cracked SAM and shadow password files
- Compared cracking tools and performance
- Generated custom wordlists
- Analyzed password weaknesses

## Skills Demonstrated
- Password security analysis
- Offensive security tooling
- Linux command-line usage
- Security risk assessment
