# Log Analysis & Security Monitoring Lab Overview

## Overview
This lab focuses on analyzing system log files in Windows and Kali Linux
to detect suspicious and malicious activity.

## Scope
Log files were reviewed from both Windows and Kali Linux systems,
including authentication, application, and system logs.

## Tools Used
- Windows Event Viewer
- Logwatch
- Wazuh

## Analysis
Scripts were executed on the virtual machines to simulate malicious
behavior. Log analysis revealed actions including:
- User creation and deletion
- Privilege escalation
- Log clearing
- System modifications

These activities are commonly associated with exploitation and
anti-forensics techniques.

## Skills Demonstrated
- Log analysis
- Security monitoring
- SIEM concepts
- Incident detection
- Windows and Linux administration
