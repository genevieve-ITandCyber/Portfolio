# Mininet & Wireshark Network Analysis Lab

## Overview
This lab focuses on using Mininet to simulate a virtual network and Wireshark to capture and analyze network traffic.

## Objectives
- Configure and explore a Mininet network
- Capture packets using Wireshark
- Analyze ARP and ICMP traffic
- Understand packet-level network communication

## Tools & Technologies
- Mininet
- Wireshark
- Linux
- VirtualBox

## Skills Demonstrated
- Network simulation
- Packet capture and analysis
- ARP and ICMP analysis
- Linux networking
