# iPerf3 Bandwidth & Throughput Analysis Lab

## Overview
This lab explores network bandwidth and throughput using iPerf3 in a
controlled environment.

## Objectives
- Understand bandwidth vs. throughput
- Measure TCP and UDP performance
- Analyze congestion and jitter

## Tools & Technologies
- iPerf3
- Mininet
- Linux

## Skills Demonstrated
- Network performance testing
- TCP/UDP analysis
- Linux networking
